<h1>To-Do-List app</h1>
<p>A simple, fast, and user-friendly task management app that helps you plan your day,
track your progress, and stay organized.</p>

<h2> ✨ Features:</h2>
<ul>
<li>Login,home,logout,add, and delete tasks</li>
<li> Remove the tasks once it has completed</li>
<li>Data persists after refresh (Local Storage)</li>
<li>Responsive design for desktop and mobile</li>
<li>Clean, minimal interface</li>
</ul>
<h2> 🛠️ Built With:</h2>
